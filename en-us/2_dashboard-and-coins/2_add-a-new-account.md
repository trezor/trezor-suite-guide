# Add a new account

Multiple accounts can be created for each asset. You can create additional accounts to separate your funds, or manage them on one account using multiple addresses.

* Click on the plus icon (➕) at the top of the **Accounts** sidebar
* This will open the **Add account** menu, where you can:&#x20;
  * **Add** an account to an already active network.
  * Activate another network and **Add** associated account(s).

The new account can be the same type as an existing account as long as the preceding one has been used, _i.e._, you cannot create multiple _empty_ accounts of the same type.

> 💡 Learn more about [managing accounts in Trezor Suite](https://trezor.io/guides/trezor-suite/trezor-suite-desktop/manage-accounts-in-trezor-suite) on the Trezor knowledge base
